# GoldenWA Guides

A small library of practical, honest guides for Golden WhatsApp (GoldenWA) users, published as a GitHub Pages site.

Each guide covers one topic properly:

- **Status Saver Guide** — watching statuses quietly and saving them before they expire
- **Scheduler & Business Guide** — message scheduler, auto reply and broadcasts for busy people
- **Safety Guide** — an honest look at the risks of using a WhatsApp mod, and the habits that manage them
- **New Phone Guide** — moving GoldenWA to a new handset without losing chats
- **Install Errors Guide** — what Android's APK error messages actually mean, and how to fix them

The guides are plain HTML pages with no build step. Open `index.html` or browse the live site to read them.
